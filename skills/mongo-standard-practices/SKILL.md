# MongoDB Standard Practices

This skill is a draft. Project-specific conventions will be developed with the repository owner.

Inspect representative queries, existing indexes, driver usage, and expected data volume before proposing query changes.

Follow the project's established conventions and the user's explicit requirements. Do not present unconfirmed preferences as repository standards.
